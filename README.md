# Property Post Maker

A polished web application that generates ready-to-share real-estate property creatives from four simple inputs.

## Features

- Property & Type input
- Location input
- Price input
- Highlights input
- Live property post preview
- Automatic branding
- Automatic contact information
- Automatic creator name
- 1080 x 1350 PNG export
- Responsive design
- Client-side generation
- Vercel deployment ready

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS

## How to Run

```
npm install
npm run dev
```

## Production Build

```
npm run build
```

## Project Flow

```
User enters property details
        ↓
Generate Post
        ↓
Preview creative
        ↓
Download PNG
```
